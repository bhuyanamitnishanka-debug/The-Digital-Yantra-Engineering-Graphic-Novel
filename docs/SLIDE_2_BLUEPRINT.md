## 🎨 Visual Layout & Theme Variables

* **Background Canvas Color:** Parchment Cream (`#F7F4EB`)
* **Visual Layout Element:** Split the slide into two equal vertical columns.
* **Left Column:** Dark, structured typography defining the structural problem.
* **Right Column:** A light background card box (`#FFFFFF` with a 1px dashed `#00A8B5` outline) containing a snippet of raw, unreadable hardware JSON code to visually represent "Dry Documentation."

## 🎙️ Speaker Notes (Paste directly into Slide 2 notes)

> "On Slide 2, we address the core operational friction present in contemporary consumer hardware companies. Right now, there is an immense disconnect between low-level hardware documentation and high-level launch storytelling.
>
> On one end, brilliant engineering assets—like the 12-layer HDI PCB layouts or 7-element lens clearances shown in the code block on the right—remain buried in dry tables. On the other end, consumer marketing abstracts this complexity away completely.
>
> Furthermore, when teams try to bridge this gap on the web using heavy 3D asset engines, they run into performance issues on mobile viewports. The Digital Yantra acts as a framework to solve all three points: turning strict CAD constraints into smooth, human-centric visual novel narratives that run flawlessly at 60 frames per second."
